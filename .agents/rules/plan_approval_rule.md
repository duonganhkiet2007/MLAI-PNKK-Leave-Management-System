# QUY TẮC BẮT BUỘC: LÊN KẾ HOẠCH VÀ CHỜ NGƯỜI DÙNG PHÊ DUYỆT TRƯỚC KHI CODE

1. **Luôn lập kế hoạch trước khi thay đổi code**: Với mọi yêu cầu chỉnh sửa, tính năng mới hoặc thay đổi giao diện/logic, Antigravity BẮT BUỘC phải lập kế hoạch chi tiết (`implementation_plan.md`) và thông báo rõ ràng cho người dùng.
2. **Không tự ý viết code khi chưa có xác nhận**: Tuyệt đối KHÔNG ĐƯỢC tự ý chỉnh sửa file mã nguồn (`.py`, `.js`, `.html`, `.css`,...) hay chạy các lệnh thay đổi dữ liệu trước khi người dùng gửi phản hồi ĐỒNG Ý / PHÊ DUYỆT kế hoạch.
3. **Chỉ triển khai sau khi được chấp thuận**: Sau khi người dùng xác nhận "đồng ý" / "ok" / phê duyệt kế hoạch, mới được phép tiến hành code và cập nhật file theo đúng phạm vi đã duyệt.
